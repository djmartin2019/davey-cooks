# Davey Cooks

A personal cooking journal and recipe site. Good food, some experiments, a few lessons learned.

Built with Next.js (App Router, static export), TypeScript, Tailwind CSS, and MDX.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
```

- Recipes: `content/recipes/*.mdx`. See [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md) and [docs/RECIPE_TEMPLATE.mdx](docs/RECIPE_TEMPLATE.mdx).
- How the site works: [docs/SITE.md](docs/SITE.md).
